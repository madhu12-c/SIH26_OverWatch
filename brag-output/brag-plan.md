# brag plan: One Nation, One Material Code (SIH26099, Team Overwatch)

**What it is:** a prototype national registry that finds when two CPSE material codes are the same physical
item by comparing specifications, not spelling, and issues one National Material Code.
**For:** CPCL / MoPNG judges at SIH 2026, and CPSE material-master reviewers.
**What sets it apart:** text similarity gets the order backwards (the pair that must never merge scores higher
than the pair that should), so matching runs on extracted specifications with veto fields, and every refusal
names the field.
**Most impressive true claim:** 15,000 records, 860 merged automatically, 0 wrong; text matchers on the same
records made 1,953 to 3,783 wrong merges. Real tender text: 4 merged, 0 wrong.
**Visual hook:** two gasket lines that differ by three characters (SS316 / SS304).
**Real UI shown:** the portal's "Case: The Block" page, captured fresh from ui/dist.
**Tone:** polished: serious, restrained, long holds, soft fades. Ministry audience.
**Share line:** "Two CPSE codes, one character apart, never the same gasket. Our prototype matches materials on
specifications, not spelling: 860 automatic merges, 0 wrong."

**Hard rules (from the team):** only numbers locked in deliverables/slide-numbers.md; "prototype" on screen;
no State Emblem, flag, ministry or company logos (the portal's own mark only); only real portal screens.
Music is composed for this video (the bundled tracks' licence is unverified and this will be public).
